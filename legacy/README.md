# Portfolio Personal — Enzo Rabossi
Este portfolio fue construido desde cero a lo largo de 6 sprints para el bootcamp Full Stack Developer + IA de The Bridge,
incorporando progresivamente HTML, CSS y JavaScript.

## Funcionalidades

- Modo oscuro/claro con persistencia en localStorage
- Header y footer dinámicos con JavaScript modular
- Skills renderizadas dinámicamente desde array de datos
- Cheatsheets de HTML, CSS y JavaScript con navegación sticky
- Página de recursos con sistema de pestañas
- Widget de clima en tiempo real con geolocalización
- Formulario de contacto funcional con FormSubmit.co
- Diseño responsive con menú hamburguesa

## 🛠️ Tecnologías

HTML5 · CSS3 · JavaScript · Git · GitHub Pages · WeatherAPI
